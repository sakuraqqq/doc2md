# doc2md v0.2.0（2026-10-21）

> 本版是**卡 058 退回重修的收口版**，也是 0.2 系列的首个版本：一处**安全修复**（预览零外发）＋一处**行为变更**（大文本分段渲染 + 4 MB 口径）。完整发布记录见 `docs/RELEASE.md` 的「## v0.2.0 · 2026-10-21」节。

## 用户能感觉到的变化

### ⭐ ① 安全修复：预览不再发出任何外域请求（R1）

此前渲染 Markdown 时，以下 7 类载体可以把 `src/srcset/poster` 带进预览 DOM，导致浏览器**直接请求外域**：

| # | 载体 | 旧行为 |
|---|---|---|
| 1 | `<img srcset>` | `src` 合法 data URI，但 `srcset` 指向外域 |
| 2 | `<picture><source>` | `source[srcset]` 原样保留 |
| 3 | `<video poster>` | poster 原样保留 |
| 4 | `<audio src>` | src 原样保留 |
| 5 | `<input type=image>` | src 原样保留 |
| 6 | `<video src>` | src 原样保留 |
| 7 | `<video><source src>` | src 原样保留 |

修复后：媒体容器（`video/audio/source/track/picture`）一律不进预览；`img` 删除 `srcset/sizes`；`input` 只保留 checkbox；sanitize 之后再加一道**属性语义总闸**（`src/srcset/poster` 逐个收口）。合法 base64 图与任务列表 checkbox 照常显示；**复制/下载仍为完整原文**。

> 真机抽查（V2573A / Android 16）：旧版打开 7 类 payload 预览 ⇒ 14 条 TCP 连接；新版 ⇒ **0 条**。

### ⭐ ② 行为变更：大文本预览改为「分段渲染」（R2）

- **首段 = 256 KB 文本**（base64 图片负载不计），下方出现 **「继续渲染（剩余约 X KB）」**；
- 点一次追加下一段，全部完成后显示 **「已全部渲染」**；
- 切块按**空行**，⛔ 不从代码围栏/表格中间切；
- **4 MB 原始总上限保留**：超过即明示截断（沿用旧提示「（渲染预览已截断，完整内容请复制/下载）」）；
- 单图 ≤2 MB 规则不变；图片不占文本预算。

**代表性性能**（真实结构夹具：1 MB = 12,504 块 / 4 MB = 49,342 块；3 次中位数）：

| 视口 | 1 MB 首屏 | 4 MB 首屏 | 1 MB 续完 | 4 MB 续完 |
|---|---|---|---|---|
| desktop 1280×800 | 341 ms | 470 ms | 1.7 s | 11.1 s |
| mobile 412×892 | 339 ms | 420 ms | 1.9 s | 11.3 s |

> 对比：修复前 1 MB 全量渲染 **1,168 ms**、4 MB **6,225 ms**（首屏目标 <500 ms；续渲染按需触发，不阻塞首屏）。

## 观察期口径（按 `docs/RELEASE-CHECKLIST.md` §5）

- **性质**：R2 属**行为变更** ⇒ 走观察期；R1 是安全修复，同样纳入本版观察面。
- **观察期不是等时间，是等信息**：滚动累积「被测版本 = **v0.2.0 发布物**」的实测与反馈；到期零反馈要写「到期结束（零反馈）」，不等同「无问题」。
- **重点观察面**：
  1. 大文件预览：首屏/续渲染是否卡顿、按钮文案与完成态；
  2. 4 MB 边界：>4 MB 文档是否明示截断（不静默）；
  3. 媒体/图片策略：含外链图、srcset、video/audio 的 md 预览是否零外域请求、占位是否正常；
  4. 短文档回归：不应出现「继续渲染」按钮；
  5. 移动视口（412×892）与手机浏览器；
  6. 复制/下载内容完整性（不受预览分段影响）。
- **版本标注**：观察期内的每次实测必须标注被测版本；测线上（= v0.2.0 产物）可关闭本版观察期，测 main 未发版只作参考。

## 已知限制（如实标注）

1. **A12 独立验收**：本轮为**执行线自验**（headless + 真机 A14 抽查 + A15 两档测量），**独立验收（不同模型/真机/他人）待做**。
2. **4 MB 以上文档**预览为**明示截断**（设计如此）；复制/下载仍完整。
3. 逐字排版的 PDF 拉丁字母/数字可能被空格打散（历史已知，非本版引入）。
4. `file://` 直开时 OCR / PDF worker 受浏览器限制；断网可用（Service Worker）。
5. 单文件 >50 MB 仍直接拒绝。
