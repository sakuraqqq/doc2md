### 1.2 HTML 相邻拉丁文本被强插空格（P1）

**位置**：`src/html2md.js` 的 `joinFrags`（“前后可见字符均 `[A-Za-z0-9]` 就补空格”规则）。

**实测（当前 index.html / Edge）：**

| 输入 | 输出 | 期望 |
|---|---|---|
| `<p>foo<span>bar</span>baz</p>` | `foo bar baz` | `foobarbaz` |
| `<p>IP<sub>v6</sub>地址</p>` 一类结构 | 同样可能被打散 | 原文无空格应保持贴靠 |

**根因**：加粗/斜体/链接包裹时对内部先 `.trim()`，片段自身丢失“原始两侧是否有空白”的信息；`joinFrags` 因此改用“相邻字母”反向推断空格。对 `Hello <b>world</b>.` 这类用例有效，但对无空格相邻的拉丁片段（span 拆分、行内标记拆词）会凭空造出空格。

**修复方向**：
1. 片段增加边界元数据（如原文本尾部/首部是否有空白），空格放到 `**`/`*`/`` ` `` 等标记**外侧**；
2. 不再仅凭“前后均为字母数字”补空格；
3. 若仍要保留“分隔元素之间视觉空白”容错，应以**原始文本节点空白**为准。

**回归用例建议**：`foo<span>bar</span>baz`、`Hello <b>world</b>.`、`这是<b>重点</b>内容。`、`The <em>quick</em> brown fox <code>jumps</code>.` 四者同时快照。

### 1.3 列表项内多个块级段落被合并（P1）

**位置**：`src/html2md.js` 的 `liToLines`：`<li>` 内遇到 P/DIV 等块级子元素直接走 `fragFor` 行内平铺，未保留块边界。

**实测：**

| 输入 | 输出 |
|---|---|
| `<ul><li><p>para one</p><p>para two</p></li></ul>` | `- para one para two` |
| `<li><div>d1</div><div>d2</div></li>` | `- d1 d2` |

**影响**：HTML 多段列表项、DOCX 多段落列表项在 htmlToMarkdown 共享路径下会丢段落结构。

**修复方向**：在 `liToLines` 内遇到块级子元素时 flush 当前片段并按“首行 marker + 续行缩进”换行，而不是继续追加；语义上可对齐 CommonMark 列表续行规则。

### 1.4 代码块内部连续空行被全局归一化吞掉（P2）

**位置**：`src/html2md.js` 末尾：

```js
return blocks.join('\n\n').replace(/\n{3,}/g, '\n\n').trim();
```

该替换对整篇生效，未保护 PRE 围栏内部。

**实测：**

```html
<pre>line1



line2</pre>
```

输出代码块内只剩 1 个空行（原 3 个空行被压缩）。

**修复方向**：块间换行归一化时跳过围栏内内容（恢复初版的 `inCode` 状态机思路），或只对“块与块之间”的换行做归一化。

### 2.3 xlsx 日期实测（本轮补证，确认 §1.3 仍开）

构造 numFmt=14 + Excel 序列号的合成 xlsx（45123 / 45292.75），Node 直跑 `src/xlsx.js` 自解析路径：

```
### Sheet: Sheet1
| 日期 |
| --- |
| 45123 |
| 45292.75 |
backend=xlsx-self warnings=[]
```

期望（按 README 宣称与库路径 Date 口径）：日期应格式化为 `YYYY-MM-DD`（至少 `45123 → 2023-07-16`），且 style 数字格式（千分位/百分比/货币）同样未做。当前实现无 error、无 warning，属静默不满足宣称。另 `t="d"` ISO 日期会原样带出时间（`2021-06-10T00:47:45.700Z`），与“日期”表述不符。

**修复方向**：解析 `xl/styles.xml` 中 cellXfs→numFmt（内置日期 id 14-22/27-36/45-47/50-58 + 自定义 formatCode 判定），序列号转日期；或检测到日期样式即回退库路径；至少发 warning「日期已按序列号输出」并同步 README/architecture。
