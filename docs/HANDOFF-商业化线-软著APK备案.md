   - 格式：A4 黑白，每页 50 行，页眉「软件名称：doc2md（文档转 Markdown 工具）· 版本 v0.1.0 · 页码」；
   - 取码：`src/` 全部（10 模块）+ `sw.js`；按「首 30 页 + 尾 30 页」（总量约 1250 行 ≈ 25 页——**不足 60 页时全部提交**；行数少于 3000 行时整体提交即可）；
   - 建议脚本：`tools/gen-copyright.mjs`（读取 src/**/*.js + sw.js → 按序 50 行/页分页 + 页眉写入 `docs/copyright/源代码-前30页.txt` 与 `后30页.txt`——若不足 60 页则生成单文件全量版）。
2. **软件说明书**（软著申请表附件）：
   - 结构模板：软件简介 / 运行环境（任意现代浏览器，建议 Chrome/Edge）/ 功能说明（5 类转换+表格+LaTeX+图片抽取+OCR+PWA/界面截图）/ 操作步骤（拖放→转换→复制/下载）；截屏用 `assets/screenshot.png` 现成图；
   - 落盘 `docs/copyright/说明书.md`。
3. **申请流程清单**：中国版权保护中心（ccopyright.com.cn）官网注册→个人实名→表格申请（软件名称/版本/开发完成日期=git 首 commit 日期（2026-09-04）/发表状态（未发表）/取得方式（原始取得）/权利范围）→ 上传源程序+说明书+身份证明 → 缴费（官方免费/加急约 ¥300）→ 受理回执 → 约 45-60 天取证。落盘 `docs/copyright/申请清单.md`。

## 四、后续步骤要点（APK/备案/商店——到那时再细做）

- **② APK**：Capacitor 方案（架构 §8.4）：`npm i @capacitor/core @capacitor/cli` → `npx cap init` → `npx cap add android` → `npx cap sync` → Android Studio 打开 `android/` 构建；**keystore 自备且不可丢**（签名密钥）；交付物为 APK（部分商店要求 AAB）。注意：Capacitor WebView 内 PWA/SW 的兼容性需实测；离线缓存与零外发在 WebView 内成立（同源）。

- **④ 商店注册**：应用宝/华为/小米/OPPO/vivo 各自开发者注册（个人实名：身份证+银行卡+软著或测试报告）；注意各商店审核差异（软著、隐私政策、图标尺寸等）。

## 五、红线与纪律（沿用，新会话必须遵守）

1. **零外发**（产品红线，宣传口径）——商业化宣传与商店申报材料不得声称"上传服务器"等违背事实的能力。
2. **发布/上架动作人执**：商店注册、备案提交、签名打包终验在用户终端；AI 只准备材料与 dry-run 命令。
3. **拍板权在人**：规模/定价/商店选择/资质路径——列拍板点，逐项确认。
4. **实测核验**：每份材料落盘后回读+按官方要求自查；APK 出包后真机试跑（至少一台安卓手机）。
5. **一会话一线**：本线新会话；与主开发线（v0.1.1 功能）分线并行时，改代码走主线的 build+CI；商业线只做材料/打包/备案。
