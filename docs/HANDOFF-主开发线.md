| 场景 | 做法 |
|---|---|
| git log | `git --no-pager log --oneline -N`（PowerShell 下分页器报 `'nutc': unknown terminal type.`） |
| **native 命令（`git`/`node`/`python`/`npm`/`npx`/`curl`/`wsl`… 一律，不限 git）** | **不加管道/重定向/表达式**：`… \| Select-Object` / `2>&1` / `\| Out-String` / `"…" + (git …)` / `$x = python …`，**以及任何重定向 —— `> 文件` / `>> 文件` / `> $null`**（`$null` 也是重定向目标，不是「丢弃输出」的语法糖） → `Program 'git.exe' failed to run: Access is denied` 或 `StandardOutputEncoding is only supported when standard output is redirected`（沙箱禁命名管道，**命令根本没执行**——易误判为 commit/fetch 失败）；native 输出一律写成**独立语句**。⚠️ 正因命令没执行，**此时 `$LASTEXITCODE` 是上一项的残留值、一律不可采信**（2026-09-19 卡 004 自测：先 `git --version`(0) 再撞 `python … > $null` 坑 → `$LASTEXITCODE` 仍是 **0**，看着像成功）；且 **`> 文件` 会留下 0 字节的假产物**（PS 先建目标文件、进程没起来）⇒ **"文件存在"≠"命令跑了"**，判成败要看**副作用（且非空）**。安全目录前缀写 **`-c safe.directory=*`（不带引号）**——`'*'` 在 pwsh 下引号被吞 → `fatal: detected dubious ownership`（2026-09-15 实测；同进程三件套 `$env:GIT_CONFIG_COUNT=1` / `GIT_CONFIG_KEY_0=safe.directory` / `GIT_CONFIG_VALUE_0=*` 亦可用） |
| 版本内容比对（按字节） | 取历史提交的文件内容时**必须加 `-c core.autocrlf=false`**：`git -c safe.directory=* -c core.autocrlf=false restore --source=<commit> --worktree -- <path>`。否则检出过滤器写入 CRLF（`index.html` 118,244 B → **120,410 B**），且 **git 视为无差异**；比完记得还原（同命令 `--source=HEAD`）并核 `git status` 与 SHA256 |

CAfile: none CRLfile: none`（2026-09-14 实测）；加该参数后 `ls-remote`/`fetch` 实测通。同理 Chromium 需 `--ignore-certificate-errors`（见全局 AGENTS.md「本机浏览器」节） |

## 10. 与 Linux 侧（WSL2）协作约定（2026-09-15 固化）

**投递箱** = `.私档/linux/`（gitignore，永不入库）。流程：**Windows 出单 → Linux 只读取证 / 独立验收 → 产出回箱 → Windows 实测核验并落库**；**Linux 只读不推** —— 任何 push / tag / Release 一律由用户从桌面终端执行（与红线 3 同源）。

| 目录 | 内容 |
|---|---|
| `任务-<主题>/` | **交接单**（Windows→Linux）+ 开单通知 + 补丁（`git format-patch`）+ **补件** |
| `<YYYYMMDD>-<批次>/` | Linux 侧产出：报告 + `summary.json` + 原始日志 + `回执.md` + 脚本 |

**交接单必备三件（缺一不可）**：**期望值 + 判据（探针词 / 归一化规则）+ 预期例外**。
> 2026-09-15 教训：只给了「探针命中 5/5 · 5/5 · 6/6 · 5/6」却没给**探针词与匹配口径** → 验证方无法复现，只能登记未验证项 U1；后出**补件**（探针词表 + 写死的去空白子串口径 + 预期未命中说明 + 隐私口径澄清）才关闭。**期望值必须与判据成对给出。**

**Linux 侧纪律（写进每份交接单）**：① **只读不推**（不改受控文件、不 commit/push/tag；**不跑 `npm run build`**、不装依赖，除非交接单**显式豁免**）② **只报告不修改**（发现疑似缺陷 → 另开小节 + 最小复现）③ **换环境 + 换数据 + 负对照必红** ④ 回执须含**每文件字节 + SHA256**（Windows 侧逐个实测核验，不符打回）⑤ 🔒 **隐私**：用户真机材料只在 `.私档/` 内只读，**不得复制进仓库、不得出现在报告截图或正文引用**（报告只写文件名与数字）。

**跨机比对口径**：**源码用 git blob**（`git rev-parse :<path>`，**不用**工作区 SHA256 —— Windows `core.autocrlf` 会使同内容哈希不同）；**产物用字节 + SHA256**。
