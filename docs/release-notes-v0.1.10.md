# doc2md v0.1.10（2026-10-05）

> 本版的主题是 **大文件不再把页面卡死** —— 上一版（v0.1.9，09-16 构建）之后，主线累计 **181 个提交**，其中最重要的一条是把 XLSX 的解析**改成流式**：内存占用从「跟文件一样大」降到「跟窗口一样大」。完整发布记录见 `docs/RELEASE.md` 的「## v0.1.10 · 2026-10-05」节。

## 用户能感觉到的变化

### ⭐ ① 大 XLSX 从「几乎必然卡死」变成「秒级完成」

**改前（实测基线）**：一份 **35.9 MB** 的 xlsx → 内存冲到 **11.24 GB**；**47.4 MB** 的那份 → **11 秒冲到 5 GB，被系统 SIGKILL**；极端形态下 **286.8 秒只换出 1000 行**。

**改后**：同一份大文件，组 Y 用例从 **96.8 秒 → 367 毫秒**。

**怎么做到的**：工作表 XML 与 `sharedStrings` 从「整份读进内存再解」改成 **逐块解压 + 增量解码 + 跨块续接缓冲** —— 峰值内存从 **O(文件大小)** 降到 **O(解压窗口)**。

### ⭐ ② 解析前先给提示，不再「点了没反应」

大文件在解析那几秒界面是无响应的。本版：**解析前先只读 ZIP 中央目录估规模**（按**解压后**大小判断，≥32 MB 触发）→ **先把提示条画出来**（"文件较大…页面会暂时无响应，请勿关闭"）→ 再开始解析。

配套**撤掉了旧的 4 MB 护栏** —— 它的判据本来就错位（按压缩包大小判，而不是解压后），流式化之后更没有存在的必要。

### ⭐ ③ 多文件批量转换：一个坏了，不再全批中断

以前一个文件读失败会**整批抛掉**。本版：读文件/嗅探失败**不再抛**，**逐文件隔离**，状态栏给出**成功/失败计数**，两个入口都有兜底。

### ④ 一些小而实在的修正

| 变化 | 说明 |
|---|---|
| **xlsx 数值长尾不再吓人** | 渲染层按 **15 位有效数字**显示：`34.200000000000003` → **`34.2`**（⚠️ 真精度一律**不截**，只影响显示） |
| **图片说明不再跨行** | 图片 `alt` 里的连续空白压成单空格 ⇒ `![alt](src)` 不再被拆断（DOCX 与 HTML 两条入口都修） |
| **回退路径不再静默** | 某条解析路径降级时会**说出来**；并且**回退不再丢 sheet 名** |
| **截断会写进产出** | 内容被截断时，在产物**首行插一条 HTML 注释**说明截断原因与原文位置（以前只在界面上提示） |
| **保存体验** | 保存环节不再静默、成功有回话、反馈落在**当前视口内**；APK 内可直接落到本机文件（网页版走浏览器下载） |

### ⑤ 内务（用户无感，但让以后更稳）

- **`docs/BASELINE.json` = 数字唯一真相源** + `tools/baseline-check.mjs` 守卫（发布物由 tag blob 现算 / 交付面按磁盘现算 / 契约数对账）
- **契约数自动对账**：CI 从 TAP 摘要反查 `BASELINE.json`，不符即红
- 一批守卫加固（部署 smoke 的引号/srcset/URL 语义反扫 · 交付面依赖体检 · CI 步序守卫）
- **APK/Android 线**（与本网页版无关）：Capacitor 工程入仓 · 权限面登记 · FileProvider 删除 · APK 版本号与产品对齐 · 两条产物守卫

## 已知限制（如实标注，非本版引入）

1. **逐字排版的 PDF**：拉丁字母与数字可能被**逐字空格打散**（`2026` → `2 0 2 6` 形态）。CJK 有规则抑制，拉丁/数字没有 —— **已登记待拍板**。
2. **file:// 直开**：OCR 与 PDF 的 worker 在 `file://` 下受浏览器限制（另有说明）；**断网可用**（Service Worker 离线缓存全功能）。
3. **> 50 MB 仍然直接拒绝**并提示（护栏仍在，只是判据不再错位）。
4. **PDF 版面结构还原**（表格/多栏/标题识别）**未启动** —— 属独立线，按拍板不启动。

## 升级说明

**无。** 单目录离线部署：把 `index.html` + `vendor/` + `langs/` + `icons/` + `manifest.json` + `sw.js` 一起替换即可。

⚠️ 本版 **`vendor/` / `langs/` / `icons/` 零改动**（实测 `git diff --stat v0.1.9..HEAD -- vendor langs icons` 零输出）⇒ **Service Worker 的 `CACHE_NAME` 无需 bump**，保持 `doc2md-sw-v4`。

⚠️ **首次打开若仍是旧版**：老版 Service Worker 会先接管一次 —— **刷新一次**即可拿到 v0.1.10（页脚会显示 `doc2md v0.1.10`，可用它确认）。
