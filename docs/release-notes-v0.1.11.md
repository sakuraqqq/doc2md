# doc2md v0.1.11（2026-10-09）

> 本版是**发版锚点批**：主题不在功能，而在**让「tag 指向的代码」与「挂出来的产物」重新对齐** —— 上一版 `v0.1.10`（2026-10-05）的 tag 里**不含任何 Android 线改动**（其 `build.gradle` 没有签名配置、应用名还是 `doc2md`），而挂在那个 release 下的 APK 却是**更新的代码**构建的 ⇒ **按 tag 复现构建的人（如 F-Droid）会构建出旧应用名** ✗。完整发布记录见 `docs/RELEASE.md` 的「## v0.1.11 · 2026-10-09」节。

## 用户能感觉到的变化

### ⭐ ① Android 版：应用名与图标焕新

- **应用名 = 「文转MD助手」**（上一版 tag 里仍是 `doc2md`；应用名一致性是商店/软著的红线 ✓）
- ⭐ **新图标**：折面 **M** + 蓝紫弥散渐变 + 右侧色散重影（16 件 PNG 覆盖 + 5 件背景新增 + 2 份自适应 XML 背景改指 `@mipmap`）
- **release 包开始真签名**：本仓改为「**两模式**」—— 有 `keystore.properties` 就用你的密钥签名；**没有也能构建**（⇒ F-Droid 可以用它自己的密钥复现构建 ✓）
- **版本号有了唯一真相源**：`versionCode` 由 `package.json` 的 `version` **推导**（`0.1.11 ⇒ 111`），推不出来就**直接报错**而不是静默 ✓

### ⭐ ② 文本转换的三处更正

| 变化 | 说明 |
|---|---|
| **PDF 非 BMP 字符不再丢** | 代理对（emoji、罕见汉字）此前可能被拆坏 |
| **xlsx 注音不进正文** | `<rPh>`（日文假名注音等）不再混进 Markdown |
| **OLE2 文件分型** | 老式 `.doc` / `.xls` 等给出**具体类型**提示，而不是笼统报错 |

### ③ 保存体验

- 保存落点改为 **`Download/WenZhuanMD/`**；新增**一键全部保存**（网页版与 APK 内共用一个目录名常量 ✓）

### ④ 一些小而实在的修正

| 变化 | 说明 |
|---|---|
| **导出缺图不再静默** | 收集失败项 → 卡片内 `.warnings` + 状态栏（⚠️ 产物字节**零变化** ✓） |

### ⑤ 内务（用户无感，但让以后更稳）

- `HANDOFF §5` 补一条命令坑：**原生命令失败不会自动停**（PowerShell 7.6.6 实测）⇒ 有副作用处必须显式判 `LASTEXITCODE`
- 契约登记（`meta.ole2Subtype` 五取值 + 契约组 **T45** 十条）+ `HANDOFF §8` 三处漂移更正

## 已知限制（如实标注，非本版引入）

1. **逐字排版的 PDF**：拉丁字母与数字可能被**逐字空格打散**（`2026` → `2 0 2 6` 形态）。CJK 有规则抑制，拉丁/数字没有 —— **已登记待拍板**。
2. **file:// 直开**：OCR 与 PDF 的 worker 在 `file://` 下受浏览器限制；**断网可用**（Service Worker 离线缓存全功能）。
3. **> 50 MB 仍然直接拒绝**并提示。
4. **PDF 版面结构还原**（表格/多栏/标题识别）**未启动** —— 属独立线，按拍板不启动。

## 升级说明

**网页版：无。** 单目录离线部署 —— 把 `index.html` + `vendor/` + `langs/` + `icons/` + `manifest.json` + `sw.js` 一起替换即可。

⚠️ 本版 **`vendor/` / `langs/` / `icons/` 零改动** ⇒ **Service Worker 的 `CACHE_NAME` 无需 bump**，保持 `doc2md-sw-v4`。
⚠️ **首次打开若仍是旧版**：老版 Service Worker 会先接管一次 —— **刷新一次**即可拿到 v0.1.11（页脚会显示 `doc2md v0.1.11`，可用它确认 ✓）。

**Android 版**：安装 `app-release.apk`（**已签名** ✓）。
