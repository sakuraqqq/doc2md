# doc2md v0.2.1（2026-10-21）

> v0.2.0 的补丁版：修复二轮复验退回的 **F1（首屏冷启/单行切段）** 与 **F2（引用定义跨段/列表编号）**。**不回滚 v0.2.0**；已发布版本保留。

## 用户能感觉到的变化

### ① 首屏预算按「结构」而不是只按字符

- 除 256 KB 字符预算外，新增 **块 / 表格行 / 内联标记** 三类结构预算 ⇒ 小段落地狱、表格密集、单行大量加粗不再把首屏拖慢。
- 冷启单次（新页面首次渲染）实测：结构化 1MB **120–152ms**、表格密集 1MB **~30ms**、34 万小段落 1MB **~50ms**、960KB 单行 **~103ms**。
- ⚠️ 测量口径改为**冷启单次**：不再用「预热 5 次取最小」当结论。

### ② 单行大文档也有「继续渲染」

- 无换行文本按内联标记/字符强制切段（surrogate 安全）；单张图片/链接（data URI）视为原子块不切，避免把 >2 MB 图截成裂图。

### ③ 引用式链接跨段仍解析

- 全量预扫 `[label]: url` 定义（跳过代码围栏）并注入每个片段 ⇒ 定义在 256KB 之后时，首段 `[链接][a]` 仍正确解析。

### ④ 切分限制明示

- 超大单表可能在行边界切开、松散有序列表跨段编号可能重开 —— 预览中给一句说明，不静默。

## 已知限制（如实）

1. 单表超预算会拆成两段（UI 明示）；列表编号未做续接，仅提示。
2. 单个代码围栏超过预算仍不切（围栏内不切是既有约束）。
3. A12 仍为**自验**（headless + 真机抽查），**独立验收待做**。
4. 4 MB 以上仍明示截断；单图 >2 MB 仍拒绝。

## 升级说明

**网页版**：替换 `index.html` + `vendor/` + `langs/` + `icons/` + `manifest.json` + `sw.js`。`vendor/langs/icons/sw.js` 零改动 ⇒ `CACHE_NAME` 保持 `doc2md-sw-v5`；首次打开若仍是旧版，刷新一次（页脚应显示 `doc2md v0.2.1`）。
